# Univox —— 多平台语音协议集成库 · 功能列表规划（v2 修订版）

## 修订说明
按反馈调整：**TS3 部分不再以 tsclientlib 的实现范围为界，而是按 TS3 平台的完整功能面规划**；tsclientlib 未覆盖的能力全部补入，用 ★ 标注。其余决策不变：Rust 实现（预留 FFI/WASM 多语言绑定）、TS6 仅作未来项、音频为 PCM 流抽象、库名 **Univox**（uni+vox）。

## 调研结论（已完成）
- **TS3（参考 ReSpeak/tsclientlib + 完整 ServerQuery/ClientQuery 文档）**：UDP 原生客户端协议 + 独立的 ServerQuery 管理接口（telnet 10011 / SSH 10022）。identity 身份体系（hash-cash 安全等级）、状态簿记、完整权限组体系、文件传输、Opus 音频、whisper、SRV/TSDNS。
- **KOOK**：官方 Bot API（REST + WS 网关，~35 事件，sn 序号 RESUME 断线恢复）；语音 = REST 换 RTP 地址后 UDP 推流 Opus（只推不收）。
- **OOPZ**：无官方开放平台，逆向客户端协议（账号登录 + JWT/RSA 签名 + 伪装客户端头）；WS 整数事件 + 按域订阅；语音走 Agora RTC（社区 SDK 用浏览器桥）。
- **TS6**：服务端 beta9，无公开 SDK；语音线路与 TS3 兼容；ServerQuery 沿用 TS3 命令（SSH/HTTP）；聊天基于 Matrix → 按决策仅作未来项。

## TS3 平台完整功能面 vs tsclientlib 差集（★ = tsclientlib 未实现，本库补充规划）
- ★ **ServerQuery 管理驱动**：login/logout/use/whoami/quit、servernotifyregister 事件注册、queryloginadd/del/list 查询账号管理 —— 独立于客户端协议的第二条接入路径（管理机器人必需；TS6 兼容复用）
- ★ **运行时自身状态（clientupdate 全字段）**：频道指挥官、优先说话者、录音中标记、徽章、客户端描述、meta_data、default_token
- ★ **头像/图标/频道横幅管理**：基于文件传输通道（`/avatar_<clid>`、`/icon_<iconid>`）的上传/下载/删除封装
- ★ **Whisper 列表管理**：客户端本地 whisper 目标列表抽象（客户端/频道混合目标、≤65 上限、whisper power 校验）
- ★ **3D 定位音频**：纯客户端本地渲染（listener 属性 + 每用户 voice position）
- ★ **客户端本地操作**：对单个用户的本地音量调节、本地静音（clientmute/unmute）、服务器/频道密码本地 hash 校验（hashpassword/verifychannelpassword）
- ★ **clientdb 管理**：clientdblist/find/info/edit/delete（查询账号数据库）
- ★ **ID 映射查询**：clientgetids / clientgetuidfromclid / clientgetdbidfromuid / clientgetnamefromuid / clientgetnamefromdbid
- ★ **自定义字段**：customsearch / custominfo
- ★ **频道内成员列表**：channelclientlist / channelclientvariable
- ★ **clientfind**（按名字查用户）
- ★ **插件命令转发**：plugincmd（PluginTargetMode: SINGLE/CURRENT_TAB/CLIENTS/ALL，客户端间经服务器中继）
- ★ **发言权授予流**：管理员向请求者授予临时 talk-power 服务器组
- ★ **反洪水处理**：`client is flooding` 错误识别 → 统一退避策略
- 服务器属性管理补充：antiflood 参数、serveridgetbyport 等

## 共同点 → 统一抽象的依据
1. 连接生命周期同构：配置 → 鉴权 → 握手 → 会话（心跳）→ 断线重连/恢复 → 断开
2. 实体模型对应：服务器(=Server/Guild/域)、频道(含语音房)、成员、消息、角色组、权限
3. 都有事件推送但形态不同（TS3 属性变更流 / KOOK 网关事件 / OOPZ 整数事件）→ 统一事件映射 + RawEvent 透传
4. 都有语音进出 + 音频传输，传输方式差异大 → 音频源/汇抽象 + 平台传输适配器
5. 都有管理面（踢出/封禁/移动/禁言类）
6. 非通用能力 → 能力声明（capability）+ 平台扩展层

### `docs/FEATURES.md`（中文，完整功能列表）章节结构

- **0. 设计目标与总原则** — 统一 API + 插件式平台驱动（trait）；状态簿记；统一事件总线；能力声明；同进程多平台多会话；Rust 核心 + 多语言绑定预留（接口不泄漏平台类型）
- **1. 核心数据模型** — `Platform`、`Session`、`Server`、`Channel`（kind: voice/text、层级+排序、密码/锁、上限、持久性）、`Member`（在线/角色/所在频道/静音闭麦/发言状态/频道指挥官/优先说话者/bot 标记）、`Message`、`Role`、`Permission`、统一 `Id` 包装
- **2. 连接与会话生命周期** — `ConnectOptions` builder（地址/凭据/昵称/初始频道/初始静音/版本伪装）；生命周期状态机；心跳保活（TS3 keepalive / KOOK 30s PING / OOPZ event 254）；断线自动重连 + 会话恢复（KOOK sn+session_id、OOPZ JWT 续期、TS3 超时重连）；断开原因与临时断开事件；多会话管理器；连接统计（丢包/带宽）
- **3. 身份与凭据** — `CredentialProvider` 抽象：TS3 identity（生成/安全等级提升/序列化 keystore）、KOOK Bot token + OAuth2、OOPZ 账号登录 + JWT/RSA 自动续期；本地加密存储接口
- **4. 服务器状态簿记** — 服务器/频道树/成员/角色内存镜像；属性变更事件驱动（参照 ts-bookkeeping）；查询 API 与缓存一致性（REST 拉取 + WS 增量）
- **5. 事件系统** — 统一事件总线（async Stream + 回调双模式）；事件分类（连接/服务器/频道/成员/消息/语音/角色权限/管理）；平台原生事件 → 统一事件映射表；`RawEvent` 透传；订阅与本地过滤
- **6. 语音模块** — 语音频道加入/离开/被移动事件；发送端：`AudioSource`（f32 PCM 48k）+ Opus 编码 + 平台传输适配（TS3 UDP voice / KOOK RTP 推流 / OOPZ Agora 桥）；接收端：抖动缓冲、分用户队列、混音、每用户音量、说话起止事件（能力分级：TS3 双向 / KOOK 仅推流 / OOPZ 桥接）；★ whisper 发送 + whisper 列表管理；★ 3D 定位音频（listener + 每用户位置）；★ 本地操作（per-client 音量、本地静音）；播放文件/URL 便利层
- **7. 消息模块** — 发送目标（频道/私信/服务器广播/Poke 通知）；内容抽象（纯文本/富文本/提及/引用/卡片）；编辑/撤回事件；reactions；历史查询；置顶；按钮点击事件；★ 离线消息管理（TS3）
- **8. 频道与服务器管理** — 频道 CRUD/排序/密码/上限/编解码器/音质；服务器信息查询/编辑；用户移动；★ 服务器/频道快照（TS3）
- **9. 成员与角色权限** — 成员查询（列表/详情/在线）；★ clientdb 管理；★ ID 映射；★ 自定义字段；★ 频道内成员列表；★ clientfind；角色 CRUD/授予/撤销；权限查询与检查；★ 发言权请求/授予流
- **10. 管理与安全** — 踢出；封禁/黑名单（按 IP/名字/UID/硬件 ID/时长）；文字禁言；语音禁麦；投诉（TS3）；★ 反洪水退避
- **11. 平台扩展层（非通用能力）** —
  - **TS3**：★ ServerQuery 管理驱动（telnet/SSH + 查询账号管理 + servernotifyregister）；★ 插件命令转发；★ 头像/图标/横幅；★ 运行时自身状态（频道指挥官/优先说话者/录音标记/徽章/描述）；★ 服务器/频道密码本地校验；privilege key；临时密码；SRV/TSDNS 解析；文件传输（含配额）；日志查看/写入；频道树订阅；myTeamSpeak 徽章/ID 变量
  - **KOOK**：webhook 接入模式；OAuth2；CardMessage 构建器；表情管理；好友；游戏状态；帖子/线程
